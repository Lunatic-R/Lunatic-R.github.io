A software tool for camera-trap image annotation and data management,
developed as the first developer for the camera-trap monitoring workflow of
our group (copyright holder: Xishuangbanna Tropical Botanical Garden, CAS).

It handles image annotation and data organization for large-scale camera-trap
projects, from raw field SD cards to analysis-ready detection tables.

Software copyright registration has been formally submitted (2026).
